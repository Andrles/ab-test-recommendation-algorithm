# A/B-тест нового алгоритма рекомендаций

## Цель проекта

Оценить, улучшает ли новый алгоритм рекомендаций вовлечённость пользователей развлекательного приложения с бесконечной лентой.

## Бизнес-гипотеза

Новый алгоритм рекомендаций увеличит долю успешных сессий — сессий, в которых пользователь просмотрел **четыре и более страницы**.

## Данные

Использованы учебные обезличенные данные Яндекс Практикума:

- история сессий приложения;
- данные первого дня теста для мониторинга;
- данные полного периода A/B-теста.

Исходные CSV-файлы не размещены в репозитории, поэтому Notebook предназначен для просмотра логики анализа и сохранённых результатов.

## Дизайн эксперимента

| Параметр | Значение |
| --- | ---: |
| Уровень значимости | 0.05 |
| Мощность теста | 80% |
| Минимальный детектируемый эффект | 3% |
| Расчётный размер группы | 17 441 пользователь |
| Ключевая метрика | Доля успешных сессий |

## Что было проверено

- динамика регистраций и вовлечённости по историческим данным;
- необходимый размер выборки и длительность эксперимента;
- отсутствие пересечений пользователей между группами;
- равномерность распределения по устройствам и регионам;
- статистическая значимость разницы ключевой метрики с помощью критерия хи-квадрат.

## Результаты

| Метрика | Группа A | Группа B | Изменение |
| --- | ---: | ---: | ---: |
| Доля успешных сессий | 30.77% | 31.83% | +1.06 п.п. |

- Относительный рост ключевой метрики составил **3.43%**.
- `p-value = 0.000323`, что ниже порога 0.05: разница статистически значима.
- В контрольный день не обнаружено пересечений пользователей между группами.
- Распределение по устройствам оказалось однородным (`p = 0.4400`).
- По регионам обнаружена неоднородность (`p = 0.0028`), поэтому вывод нужно интерпретировать с учётом этого ограничения и дополнительно проверить на полном периоде теста.

## Рекомендация

Новый алгоритм показывает статистически значимый рост вовлечённости. Перед полным внедрением следует подтвердить, что региональный дисбаланс не влияет на итоговый эффект; после этого алгоритм можно масштабировать.
